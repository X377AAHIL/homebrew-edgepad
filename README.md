## Install

```bash
brew tap X377AAHIL/edgepad
brew install --cask edgepad
```

Or in one line:

```bash
brew install --cask X377AAHIL/edgepad/edgepad
```

## What is EdgePad?

Slide along any edge of your MacBook trackpad to control volume, brightness, media playback, and more — no buttons, no shortcuts, just natural gestures.

**[Learn more →](https://github.com/X377AAHIL/EdgePad)**
